# Solar-Microgrid-Model-for-Carbon-Footprint-Lifetime-Analysis
A solar-powered microgrid model made on MATLAB/Simscape Electrical, meant to simulate analyze the CO2e footprint of solar-powered microgrid systems over 25 years. Additionally, a coal-powered microgrid is also modelled. In this project, I compare the carbon footprints of both and output data with a MATLAB script.
